## Description

Cyber Concept Paint は、コンセプトアートの初期アイデア出しに特化した iPhone 向けペイントアプリです。

キャラクター、メカ、建物、背景の形を考えるとき、いきなり大きなキャンバスで描き込むよりも、小さなラフをたくさん並べて比べた方が良い案を見つけやすいことがあります。Cyber Concept Paint は、その「ラフを量産して比較する」時間に集中できるように設計されています。

起動したらすぐにラフボード。1 画面に複数のキャンバスを並べ、気になる案だけをタップして拡大し、描き込んだらまた一覧で比較できます。明暗チェック、左右反転、レイヤー、ブラシ切り替え、スポイト、画像保存など、ラフ制作に必要な操作を素早く呼び出せます。

ブラシは少数精鋭。質感のあるブラシ、面を置くためのブラシ、水彩、油彩、鉛筆など、アイデア探索で使いやすい道具を中心にしています。派手な機能を増やすよりも、短い時間でたくさん試せることを重視しています。

主な機能:
- 複数キャンバスを並べて比較できるラフボード
- 2 x 3 など自由な行列設定
- キャンバスサイズと縦横入れ替え
- 明暗チェック、左右反転
- レイヤー、レイヤー名変更、表示切り替え
- 質感ブラシ、面ブラシ、水彩、油彩、鉛筆
- スポイト、消しゴム、Undo
- 描いた画像を写真へ保存
- 日本語/英語表示切り替え
- 7 日間のトライアルと Pro 買い切り

アイデアをきれいに仕上げる前に、まずは強い形を探す。Cyber Concept Paint は、そんなコンセプトアートの入口を支えるためのペイントツールです。

## English Subtitle

Concept sketchboards for rapid ideas

## English Promotional Text

Create, compare, and refine multiple rough concepts on one board. Built for silhouette exploration, composition thumbnails, and fast visual ideation.

## English Description

Cyber Concept Paint is an iPhone painting app focused on early concept art exploration.

Instead of starting with one large canvas, you can place multiple small canvases on a rough board, sketch many ideas quickly, and compare them at a glance. It is built for the moment when you are searching for strong silhouettes, compositions, character shapes, mecha designs, buildings, and background ideas.

Tap a thumbnail to enlarge it, draw, then return to the board to compare every idea. Use value check, flip, layers, brush switching, eyedropper, undo, and image export without leaving the flow.

Key features:
- Rough board with multiple canvases
- Flexible row and column layout
- Custom canvas size and orientation swap
- Value check and horizontal flip
- Layers with names and visibility
- Texture, block-in, watercolor, oil, and pencil brushes
- Eyedropper, eraser, and undo
- Save drawings to Photos
- Japanese and English interface
- 7-day trial and one-time Pro purchase

Cyber Concept Paint is made for finding the idea before polishing it.

## App Privacy Draft

App Store Connect の回答時のたたき台です。最終回答は、AdMob の設定と Apple の画面上の選択肢に合わせて確認してください。

- アプリ独自のアカウント作成: なし
- アプリ独自サーバーへの描画データ送信: なし
- カメラ、位置情報、連絡先、マイク: 使用なし
- 写真: ユーザーが画像保存を行う場合のみ、写真ライブラリへの追加に使用
- 端末内保存: プロジェクト、描画データ、レイヤー、ブラシ設定、表示言語など
- 第三者SDK: Google AdMob, Apple StoreKit
- Data Used to Track You: AdMob の広告設定に応じて「Device ID」「Product Interaction」「Advertising Data」などを確認
- Data Linked to You: アプリ独自では収集なし。購入情報は Apple により処理
- Data Not Linked to You: 広告関連情報、使用状況データ、診断情報など AdMob SDK の実態に応じて確認
