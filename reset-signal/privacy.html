Reset Signal プライバシーポリシー

本ポリシーは、iPhoneアプリ「Reset Signal」（以下「本アプリ」）における情報の取り扱いを説明します。本アプリはOpenAIの非公式アプリであり、OpenAIとの提携・公認関係はありません。

公開情報の取得

本アプリは、特別リセットや一時的な利用枠変更に関する兆候を検出するため、端末からOpenAI Developer Communityの公開RSSへ接続し、記事のタイトル、概要、リンク、公開日時、GUID等を取得します。通常のインターネット通信と同様に、接続先にはIPアドレスや本アプリのユーザーエージェント等が伝わる場合があります。接続先における情報の取り扱いは、そのサイトのポリシーに従います。本アプリの運営者が独自サーバーでRSSリクエストを受信・保存することはありません。

端末内に保存する情報

検出履歴、情報源の取得状態、最終確認日時、既読記事識別子、通知設定、初回説明の完了状態を端末内に保存します。OpenAIアカウント、ログイン情報、APIキー、Codexの実際の利用量、氏名、メールアドレスは本アプリへ入力せず、本アプリの運営者へ送信されません。

通知とバックグラウンド更新

ユーザーの許可を得た場合に限り、検出情報や任意のリマインドを端末のローカル通知として表示します。通知内容は端末上で生成され、本アプリ独自の通知サーバーへ送信されません。通知はiOSの設定から無効にできます。公開RSSのバックグラウンド確認時刻はiOSが決定します。

広告と第三者SDK

本アプリはバナー広告の表示と同意管理のため、Google Mobile Ads SDKおよびGoogle User Messaging Platform SDKを利用します。Googleは広告配信、測定、不正防止、分析、サービス改善のため、IPアドレスから推定されるおおよその位置情報、端末識別子、広告データ、製品操作、クラッシュ情報、パフォーマンス情報、その他診断情報を収集または処理する場合があります。一部の情報は端末またはユーザーに関連付けられる場合があります。

広告の種類とデータ利用は、地域、同意内容、端末設定、Google側の広告設定により異なります。本アプリはApp Tracking Transparencyの許可ダイアログを表示せず、IDFAへのアクセスを要求しません。該当地域では広告読込前に同意画面を表示し、必要な場合はアプリの設定画面から広告のプライバシー設定を再表示できます。Googleによる情報の取り扱いは、Googleプライバシーポリシーをご確認ください。

アカウント、分析、課金

本アプリはアカウント登録、ログイン、クラウド同期、Firebase、運営者独自の行動分析サービス、アプリ内課金、サブスクリプションを使用しません。

保存期間と削除

端末内の履歴と設定は、本アプリを削除するまで保持されます。現在、アプリ内に履歴の一括削除機能はありません。本アプリをiPhoneから削除すると、端末内のアプリデータも削除されます。Googleが処理する情報の保存期間と削除方法は、Googleのポリシーおよびユーザーの広告・同意設定に従います。

ユーザーの選択

  • 通知は初回確認時またはiOSの設定から拒否・無効化できます。
  • 該当地域では、アプリの設定画面から広告の同意内容を変更できます。
  • 端末内データは、本アプリを削除することで削除できます。

お問い合わせ

本ポリシーや情報の取り扱いに関するお問い合わせは、tani@ymail.ne.jpまでご連絡ください。

English

Reset Signal is an independent app and is not affiliated with, endorsed by, or sponsored by OpenAI. The app downloads public OpenAI Developer Community RSS metadata directly from the device. Normal requests may disclose an IP address and app user agent to the community host; the developer does not receive these requests through a first-party server. Detection history, source status, seen item identifiers, notification preferences, and onboarding state are stored locally. The app does not collect OpenAI credentials, API keys, actual Codex usage, names, or email addresses.

Optional notifications are generated locally, and background refresh timing is controlled by iOS. Google Mobile Ads and User Messaging Platform may process approximate location, device identifiers, advertising data, product interactions, crash data, performance data, and diagnostics for advertising, measurement, analytics, fraud prevention, and service improvement. The app does not request IDFA access through App Tracking Transparency. Consent choices are shown where required and can be reopened in Settings when available. The app has no account system, cloud sync, Firebase, first-party analytics, purchases, or subscriptions. Local app data remains until the app is removed. Contact: tani@ymail.ne.jp.
