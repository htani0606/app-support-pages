## Description

アプリスクショメーカーは、iPhone アプリの App Store 掲載用スクリーンショットを手軽に整えるための画像作成アプリです。

普段そのまま載せていたアプリ画面に、背景、iPhone フレーム、見出し、説明文を重ねて、伝わりやすいストア画像を作れます。個人開発アプリの魅力を、短い時間で見せやすくするためのツールです。

スクリーンショットを選ぶと、iPhone フレーム内に自動で配置。見出しや説明文、背景、文字色、フォントを調整しながら、仕上がりをその場で確認できます。作成した画像は写真アプリへ保存できます。

主な機能:
- スクリーンショットの配置
- iPhone フレーム付きのプレビュー
- 背景デザインの調整
- 見出し・説明文の入力
- フォントと文字色の変更
- 作成した画像の写真保存

こんな人に向いています:
- 個人開発アプリの App Store 画像を整えたい
- そのままのスクショだけでは訴求が弱いと感じている
- デザインツールを開かずに、iPhone 上でさっと作りたい
- 日本語のストア画像を手軽に作りたい

アプリの魅力が伝わる一枚を、いつものスクショから作りましょう。

## Review Notes

このアプリはアカウント登録なしで利用できます。
ユーザーが選択した画像は、App Store 用スクリーンショット画像の作成・プレビューのために端末内で処理されます。
作成した画像を写真アプリへ保存するため、写真ライブラリへの追加権限を使用します。
広告表示には Google AdMob を使用しています。

## App Privacy Draft

App Store Connect の回答時のたたき台です。最終回答は Google Mobile Ads SDK の最新 Privacy Manifest と Apple の選択肢に合わせて確認してください。

- アプリ独自アカウント: なし
- アプリ独自サーバーへのデータ送信: なし
- ユーザーが選択した画像・入力した文字・編集設定: 端末内で処理
- 端末内保存: 編集設定、作成画像の保存先は写真アプリ
- 権限: 写真ライブラリへの追加
- 第三者 SDK: Google AdMob
- ATT: 現状未実装。App Tracking Transparency を追加しない限り、IDFA の利用許可は求めない
- Data Used to Track You: 識別子 > デバイスID（Google Mobile Ads SDK のPrivacy Manifestに従う）
- Data Linked to You: 位置情報 > おおよその位置情報、使用状況データ > 広告データ・製品の操作、識別子 > デバイスID
- Data Not Linked to You: 診断 > クラッシュデータ・パフォーマンスデータ・その他の診断データ
- データの利用目的: 第三者広告、デベロッパによる広告またはマーケティング、分析（Google Mobile Ads SDK のPrivacy Manifestに従う）
