光る星のレールを指でなぞるだけ。ペンタトニック、メジャー、32音クロマチックを切り替えて、誰でもすぐに宇宙っぽい音遊びを楽しめます。

## Description

スペーストーンは、画面に広がる星のレールを指でなぞって演奏する、新感覚の iPhone 楽器アプリです。

難しい鍵盤操作は必要ありません。星の並びに沿って指を動かすだけで音程が変わり、触れている場所が光りながら音になります。宇宙を漂うようなビジュアルと、なぞるだけのシンプルな操作で、思いついたフレーズをすぐに鳴らせます。

音階モードは、はじめてでも外しにくい「かんたん」、自然に曲っぽく弾ける「メジャー」、半音込みで細かく遊べる「32音」に切り替え可能。気分に合わせて、直感的な音遊びから少し踏み込んだ演奏まで楽しめます。

星の発光、中央の恒星、きらめく宇宙空間など、見た目の反応も演奏の一部。音を鳴らすたびに画面が光り、触っているだけで小さなライブ演出のような気持ちよさがあります。

主な機能:
- 指でなぞるだけの直感的な演奏
- かんたん、メジャー、32音の音階モード切り替え
- 触れた星やレールが光るリッチな宇宙ビジュアル
- iPhone横向きに最適化された演奏画面
- アカウント登録なしですぐに利用可能

楽器が弾ける人にも、弾けない人にも。スペーストーンで、星をなぞるように音を遊んでみてください。

## App Privacy Draft

App Store Connect の回答時のたたき台です。最終回答は、AdMob の設定と Apple の画面上の選択肢に合わせて確認してください。

- アプリ独自のアカウント作成: なし
- アプリ独自サーバーへの演奏データ送信: なし
- 位置情報、カメラ、写真、連絡先、マイク: 使用なし
- 端末内保存: 音階モード、演奏状態、レビュー依頼や広告表示の回数情報
- 第三者SDK: Google AdMob
- Data Used to Track You: AdMob の広告設定に応じて確認
- Data Linked to You: アプリ独自では収集なし
- Data Not Linked to You: 広告関連情報、使用状況データ、診断情報など AdMob SDK の実態に応じて確認

## Export Compliance Draft

独自の暗号化機能は実装していません。標準的な OS/SDK 通信以外の非免除暗号化を使っていない前提です。
