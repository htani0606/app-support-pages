リリースチェッカー サポート

「リリースチェッカー - 本番リリースを安全に管理 -」は、本番反映前の確認、Go/No-Go判断、反映後の監視までを一つの記録として管理するiPhoneアプリです。外部のデプロイシステムを操作するアプリではありません。

お問い合わせ

不具合、使い方、ご意見はtani@ymail.ne.jpまでご連絡ください。端末機種、iOSバージョン、アプリのバージョン、問題が起きた操作を添えていただくと確認がスムーズです。

基本の使い方

  1. 「新規」からサービス名を入力し、必要な入力項目とチェックテンプレートを選んでリリースを作成します。
  2. リリース詳細で「準備を開始」を押し、リリース前のチェック項目を確認します。
  3. ブロッキング項目が完了したらGo/No-Goを判断し、反映を記録します。
  4. リリース後チェックと監視値を記録し、問題がなければリリースを完了します。

よくある確認事項

  • 入力項目を減らしたい: 設定の「新規リリース」から、表示する項目と必須条件を変更できます。
  • チェック項目を変えたい: 「チェック」でテンプレートを作成・複製・編集できます。作成済みリリースのチェックリストから、そのリリースだけの項目も追加・編集・削除できます。
  • 進められない: 未完了のブロッキング項目を確認してください。ブロック設定は各チェック項目の編集画面にあります。
  • 通知が届かない: iOSの「設定」から本アプリの通知が許可されているか確認してください。
  • データを移したい: 設定の「データ」からJSONを書き出し、別の端末で読み込めます。クラウドへの自動同期は行いません。
  • 広告が表示されない: 通信状況、同意状態、広告在庫により表示されない場合があります。広告が表示されなくてもリリース管理機能は利用できます。
  • リリースを削除したい: 個別リリースのメニューから削除できます。すべて削除する場合は設定の「全データを削除」を使用してください。

データの削除

個別リリースの削除、または設定画面から全データの削除ができます。削除した記録は復元できないため、必要に応じて先にJSONバックアップを書き出してください。アプリをiPhoneから削除すると、端末内のアプリデータも削除されます。

プライバシー

リリースチェッカー プライバシーポリシー

English support

Release Checker records preflight checks, Go/No-Go decisions, deployment milestones, and post-release monitoring. It does not operate an external deployment system. For help, email tani@ymail.ne.jp with your iPhone model, iOS version, app version, and the steps that caused the issue. Release data is stored locally; use JSON export and import for manual backup and transfer.
