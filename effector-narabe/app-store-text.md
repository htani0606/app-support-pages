## Promotional Text

## Description

エフェクター配置は、ギターやベースのエフェクターボードを組む前に、ボード上のサイズ感と配線イメージを確認するための iPhone アプリです。

ボードの横幅・縦幅を mm 単位で入力し、使いたいエフェクターのサイズを登録。登録したペダルを画面上で動かしながら、実際のボードに近い感覚でレイアウトを検討できます。

エフェクター写真を選択して、配置確認用のペダル画像として利用することもできます。サイズだけの四角い配置ではわかりにくい見た目の印象も、より直感的に確認できます。

信号チェーン、配線ガイド、スイッチャーのループ設定にも対応。物理的な並びと音の流れを分けて考えられるので、単純な直列ボードからスイッチャーを使った構成まで、組み始める前の検討に役立ちます。

主な機能:
- ボード寸法を mm 単位で入力
- エフェクターの名前、幅、高さ、写真を登録
- タッチ操作でボード上に配置
- 信号チェーンの並び替え
- スイッチャーのループ数とループ内容の設定
- 配線ガイドの表示切り替え
- 登録データの端末内保存

実際にケーブルを切ったりペダルを固定したりする前に。エフェクター配置で、ボード全体の収まりと音の流れを先に試してみてください。

## App Privacy Draft

App Store Connect の回答時のたたき台です。最終回答は、AdMob の設定と Apple の画面上の選択肢に合わせて確認してください。

- アプリ独自のアカウント作成: なし
- アプリ独自サーバーへのボードデータ送信: なし
- 位置情報、連絡先、マイク、カメラ: 使用なし
- 写真: ユーザーが選択した写真を、配置用画像作成のために使用
- 端末内保存: ボード寸法、ペダル情報、配置、配線、ループ設定、写真由来の配置用画像
- 第三者SDK: Google AdMob
- Data Used to Track You: AdMob の広告設定、ATT/同意設定に応じて確認
- Data Linked to You: アプリ独自では収集なし
- Data Not Linked to You: 広告関連情報、使用状況データ、診断情報など AdMob SDK の実態に応じて確認
